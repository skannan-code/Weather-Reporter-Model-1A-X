Frequently Asked Questions

What is this website about?
This is WeatherReporter! A free, open-source project that allows users to visit past weather reports!
How far back does WeatherReporter have weather data?
I have tested many cities, and so far, the average point of time it starts looks like around late 2007. But feel free to experiment it yourself!
What sources does WeatherReporter use to log its data?
This project was created using data from Meteostat, a weather company. It double-checks its accuracy using Geocode.
What if I accidentally typo an input?
No worries! WeatherReporter also autocorrects up to 90% of spelling and grammar errors!
Is there anything else I should know?
Thanks for asking. In fact, yes. WeatherReporter only allows 500 weather reports every month. If this limit is exceeded, the website will give you an error message.
